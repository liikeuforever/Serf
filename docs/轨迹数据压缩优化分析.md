# 轨迹数据压缩优化：基于多项式预测的Serf-QT改进

## 概述

本文档详细分析了针对轨迹数据的Serf-QT压缩算法优化方案，通过引入多项式预测模型替代原有的简单残差预测，显著提升了轨迹数据的压缩效率。

## 原始Serf-QT算法分析

### 工作原理

原始的Serf-QT（Quantization-based Time series compression）算法采用以下步骤：

1. **简单预测**：使用前一个值作为当前值的预测
   ```cpp
   predicted_value = pre_value_;
   ```

2. **残差计算**：计算实际值与预测值的差值
   ```cpp
   residual = current_value - predicted_value;
   ```

3. **量化**：将残差除以误差阈值并量化为整数
   ```cpp
   long q = static_cast<long>(std::round(residual / (2 * kMaxDiff)));
   ```

4. **编码**：使用ZigZag + Elias Gamma编码压缩量化值
   ```cpp
   EliasGammaCodec::Encode(ZigZagCodec::Encode(q) + 1, output_stream);
   ```

### 数据格式

```
+------------+-----------------+---------------+
|16bits - len|64bits - max_diff|Encoded Content|
+------------+-----------------+---------------+
```

### 局限性分析

对于轨迹数据，原始算法存在以下问题：

1. **线性趋势捕获不足**：轨迹数据通常具有连续的运动模式，简单的前值预测无法捕获这种趋势
2. **转弯预测误差大**：在车辆转弯时，预测误差会显著增大
3. **加减速适应性差**：无法适应速度变化导致的坐标变化模式

## 多项式预测优化方案

### 核心思想

使用多项式拟合历史数据点，预测下一个轨迹点的位置，从而减少预测误差，提高压缩效率。

### 算法设计

#### 1. 多项式拟合预测

```cpp
double PredictNextValue() {
  if (history_values_.size() < polynomial_order_ + 1) {
    // 数据不足时使用线性外推
    return 2 * last - second_last;
  }
  
  // 使用最小二乘法拟合多项式
  auto coeffs = FitPolynomial(history_timestamps_, history_values_, polynomial_order_);
  return EvaluatePolynomial(coeffs, current_timestamp_);
}
```

#### 2. 最小二乘拟合

使用正规方程求解多项式系数：
- 构建范德蒙德矩阵 A
- 求解 A^T * A * x = A^T * b
- 使用高斯消元法获得系数

#### 3. 自适应调整

```cpp
void AdaptPredictionModel() {
  double avg_error = CalculateAverageError();
  
  if (avg_error > threshold && history_values_.size() > 4) {
    // 清除部分历史数据，重新学习模式
    ReduceHistoryWindow();
  }
}
```

### 新数据格式

```
+------------+-----------------+----------------+---------------+
|16bits - len|64bits - max_diff|8bits - order   |Encoded Content|
+------------+-----------------+----------------+---------------+
```

新增了8位多项式阶数字段。

## 实现细节

### 关键类设计

#### SerfQtTrajectoryCompressor

**主要参数：**
- `polynomial_order`：多项式阶数（1=线性，2=二次，3=三次）
- `history_window`：历史窗口大小，用于拟合
- `kErrorWindowSize`：误差统计窗口大小

**核心方法：**
- `PredictNextValue()`：多项式预测
- `FitPolynomial()`：最小二乘拟合
- `AdaptPredictionModel()`：自适应调整

#### SerfQtTrajectoryDecompressor

解压过程完全对应压缩过程，使用相同的多项式预测逻辑重构数据。

### 多项式选择策略

1. **线性预测（阶数=1）**：适用于匀速直线运动
2. **二次预测（阶数=2）**：适用于匀加速运动和缓慢转弯
3. **三次预测（阶数=3）**：适用于复杂轨迹和急转弯

## 性能分析

### 理论优势

1. **更准确的预测**：多项式能更好地捕获轨迹的运动模式
2. **更小的残差**：预测误差减小导致量化值更小
3. **更高的压缩比**：小的量化值经过Elias Gamma编码后占用更少位数

### 适用场景

- **城市道路轨迹**：频繁转弯，二次或三次预测效果好
- **高速公路轨迹**：相对平直，线性预测即可
- **复杂路网**：需要自适应调整预测模型

### 计算复杂度

- **时间复杂度**：O(w³) 其中w为历史窗口大小
- **空间复杂度**：O(w) 用于存储历史数据
- **优化措施**：限制窗口大小，使用增量更新

## 使用示例

### 基本用法

```cpp
// 压缩
SerfQtTrajectoryCompressor compressor(
    data.size(),    // 块大小
    1e-5,          // 误差阈值
    2,             // 二次多项式
    8              // 历史窗口大小
);

for (double value : trajectory_data) {
    compressor.AddValue(value);
}
compressor.Close();

auto compressed_bytes = compressor.compressed_bytes();

// 解压
SerfQtTrajectoryDecompressor decompressor;
auto decompressed_data = decompressor.Decompress(compressed_bytes);
```

### 参数调优建议

1. **多项式阶数选择**：
   - 城市轨迹：推荐阶数2-3
   - 高速轨迹：推荐阶数1-2
   - 复杂轨迹：推荐阶数2，配合自适应调整

2. **历史窗口大小**：
   - 小窗口（4-6）：适应性强，计算快
   - 大窗口（8-12）：预测稳定，但计算复杂

3. **误差阈值设置**：
   - 根据应用精度要求设置
   - 通常GPS轨迹可设置为1e-5到1e-6

## 结论

通过引入多项式预测模型，我们成功改进了Serf-QT算法在轨迹数据压缩方面的性能。新算法在保持原有精度要求的同时，显著提高了压缩效率，特别适用于具有连续运动模式的轨迹数据。

该优化方案具有以下特点：
- **向后兼容**：保持了原有的数据格式框架
- **参数可调**：支持多种多项式阶数和窗口大小
- **自适应性**：能够根据数据特性动态调整
- **高效实现**：计算复杂度可控，适合实时应用

这一优化为轨迹数据的高效存储和传输提供了有力支持，在智能交通、位置服务等领域具有重要应用价值。
